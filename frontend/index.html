Attestation Scope & Theoretical Boundaries (Slide 11)

• User balance inclusion in committed tree
• Strict immutability post-publication
• Proof contains sibling hashes (not raw neighbour balances)
Systemic Limitations:
• Low-entropy unsalted balances are brute-forceable (recovered in ~1.3s if user ID is known; fixed by salting)
• Does not prove exchange controls wallet private keys
• Omitted users undetected without verification
